# Merchant Sheet

A Foundry VTT module for D&D 5e that adds a clean, draggable shop window to your game. Build merchant inventories by dragging items directly from compendiums, then broadcast the shop to all connected players with a single click.

---

## Features

**Item Display**
Items are organised into collapsible categories — Weapons, Armor & Equipment, Consumables, Tools, Loot, and more. Each item shows its icon, name, quantity, and price. Clicking any item opens its full item sheet from the compendium.

**Drag and Drop**
Drag any item from a compendium directly onto the shop window to add it to the inventory. Prices are read automatically from the item's D&D 5e data. Remove items with the × button that appears on hover.

**Price and Quantity Editing**
Set a custom price and currency (cp, sp, ep, gp, pp) per item. Set quantities to a specific number or leave empty for unlimited stock.

**Right-Click to Open**
Right-click any token on the canvas and select **Open Shop** to open the merchant window for that actor. Works on any actor — no special setup required.

**Broadcast to All Players**
Click **Show to All** in the shop footer to open the shop window simultaneously on every connected player's screen.

---

## How to Use

1. Place any NPC token on the canvas
2. Right-click the token and select **Open Shop**
3. Drag items from any compendium onto the shop window
4. Adjust prices and quantities using the icons that appear on hover
5. Click **Show to All** to display the shop on every connected screen

---

## Compatibility

- Foundry VTT v12 to v14
- D&D 5e system v3.0+
